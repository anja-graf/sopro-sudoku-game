# Welcome!

Thanks for downloading and playing this sudoku game, have fun!
___
## Before executing
You need the keyboard module [https://pypi.org/project/keyboard/] for navigating through the sudoku during the game. 

___
What if I don't want to install that module?

If you don't want to install the module you can also uncomment lines 280 - 282 in the user_interface class and comment out 283 - 292. For the flush() method you can uncomment 566 - 567 and comment out 569 - 570. Also you have to comment out the import statement in line 17

Now the game is also playable but it is more inconvenient because you have to type in coordinates instead of being able to navigate through arrow keys.
___

## Start the program
To start the program, execute the main method in user_interface.py!
